# Todo API Project

## Features
- Create Todo
- Update Todo
- Delete Todo
- Get All Todos
- Get Single Todo
- Query Filter Support

## Tech Stack
- Node.js
- Express.js
- JSON File (as database)

## API Endpoints

POST /todos  
GET /todos  
GET /todos/:id  
PUT /todos/:id  
DELETE /todos/:id
